    Explanation¶

    This section explains what groundfield computes, with which equations, under which assumptions and how well. Read it when you want to know why a result looks the way it does, which engine to trust for a question, or how to cite the method. Every engine page states its physical model, the equations and discretisation actually implemented, its validity range and the literature; the accuracy figures are generated from the benchmark suite rather than written by hand.

    Start here: Concepts for the overall picture, then Engines to choose the engine for your study and to see where each one must not be used.

    Page Content
    Concepts the objects of a computation, what happens in a solve, what a result contains, the modelling assumptions, the reduced \(\rho\)–\(f\) model
    Engines which engine for which question: decision path, accuracy, cost, limits of use; the governing equations and the two current models
    image · image_2layer · mom · mom_sommerfeld · fem one theory page per engine
    Kernels point source and exact line source, the Galerkin self term, field points near wires
    Earth return inductive coupling of conductors: perfect mirror, Carson, Sommerfeld / Pollaczek, skin effect
    Concrete shells the cylindrical shell of foundation electrodes and its single mechanism
    Sources and measurement two-terminal sources, junctions, input / cluster / electrode impedance, the fall-of-potential loop
    Validation and benchmarks generated tolerance table per backend, comparison figures, kernel and field checks
    Performance and scaling memory model, measured run times of this release, how they were measured

    The architecture decision records (ADRs) document why the code is built the way it is; each carries dated amendments where later releases changed a decision. Release 2026.11 amended ADR-0002, 0004, 0005, 0006, 0007, 0008, 0009 and 0012 and added ADR-0013 (calendar versioning), ADR-0014 (backend registry and shared solve pipeline), ADR-0015 (exact line-source kernel as default) and ADR-0016 (conforming finite elements in fem).
