    Geo / OSM¶

    The geo package brings real building layouts into the generators: it queries building outlines from OpenStreetMap through the Overpass API (data © OpenStreetMap contributors, ODbL), projects them from WGS84 into a local east-north frame in metres, and hands them to the generators as BuildingFootprint objects (through OsmBuildingPlacement in TnNetworkGenerator, or LvNetworkLayout.from_osm). Design and reasoning: ADR-0011.

    The active functions need the optional geo extra (pip install "groundfield[geo]": requests, pyproj, shapely); without it they raise an ImportError with the install command. The data class BuildingFootprint has no optional dependency.

    Mathematical and physical context¶

    The geo layer is topological: it decides which buildings exist, where they are and how their foundation earths are oriented. Three effects depend on that geometry rather than on the number of houses: the spreading resistance of a foundation earth grows with its buried length (the perimeter of the outline), the inductive coupling of a foundation to a PEN cable along the street depends on its orientation, and the mutual resistance between the earths depends on the real spacing of the houses, which a regular grid does not reproduce.

    Projection. Azimuthal equidistant projection (+proj=aeqd) centred on a user-supplied origin: one tangent plane, distortion below \(10^{-5}\) within about 5 km of the origin, no UTM zone bookkeeping. The origin is never inferred from the data, so two queries of the same area at different dates give identical coordinates.

    Foundation outline. A foundation earth (DIN 18014) is a closed conductor in the strip foundation. The generators reduce an outline either to its oriented minimum bounding rectangle (OMBR, the default: smallest rectangle containing the polygon, rotating calipers) or follow the polygon itself (foundation_outline="polygon" of the layout builder). An outline whose OMBR is narrower than 1 m (a mapped wall or fence) is widened to MIN_FOUNDATION_SIDE_M with a warning in both cases; a polygon foundation then follows the widened OMBR.

    Requests. Overpass queries are bounded (radius, timeout, response size), validated before they are cached, and retried with back-off; a malformed answer raises OverpassError and is not cached. Every building=* value is a footprint by default; exclude_building_tags (for example NON_SERVICE_BUILDING_TAGS: garages, sheds, carports, …) drops buildings without a service connection.

    Example (offline)¶

    import math

import groundfield as gf

# a 12 m x 9 m house turned by 30 degrees, in local metres (east, north)
angle = math.radians(30.0)
corners = [(0.0, 0.0), (12.0, 0.0), (12.0, 9.0), (0.0, 9.0)]
outline = [
    (math.cos(angle) * x - math.sin(angle) * y, math.sin(angle) * x + math.cos(angle) * y)
    for x, y in corners
]
house = gf.BuildingFootprint(polygon_xy_m=outline, osm_id=1)

centre, size, orientation_deg = house.oriented_bounding_rectangle()   # needs the geo extra
assert abs(house.area_m2() - 108.0) < 1e-9
assert abs(size[0] - 12.0) < 1e-9 and abs(size[1] - 9.0) < 1e-9
assert abs(orientation_deg - 30.0) < 1e-9

    The tutorial on TN networks (T06) builds a complete network from a stored Overpass answer, without network access; the how-to guide on OSM offline use shows how to cache and replay queries.

    API reference¶

    geo ¶

    Georeferenced data ingest for groundfield.

    This subpackage bridges the external GIS world (OpenStreetMap via the Overpass API, in the future also image-based footprint recognition) and the groundfield.generators stack. The end product is a list of BuildingFootprint instances in a local ENU frame, which a OsmBuildingPlacement then feeds into a TnNetworkGenerator so that synthetic worlds inherit real street layouts and real building outlines for the foundation electrodes.

    Optional dependencies

    groundfield.geo.osm and groundfield.geo.projection import requests, pyproj, and shapely. These ship in the geo Poetry / pip extra and are not part of the core groundfield install. Calling any of the public APIs without the extra raises a clear ImportError with the install hint::

    pip install groundfield[geo]
poetry install --extras geo

    The Pydantic data class BuildingFootprint does not depend on any of the optional libraries; it can be imported and serialised on a core install. Only the active operations (querying Overpass, projecting WGS84 to ENU, computing oriented bounding rectangles) need the extra.

    Design rationale

    See docs/adr/0011-osm-building-footprints.md for the full decision record (subpackage layout, projection choice, caching strategy, integration with the generator stack, deferred Phase B for non-rectangular foundations).

    DEFAULT_MAX_RESPONSE_BYTES module-attribute ¶

    DEFAULT_MAX_RESPONSE_BYTES = 16 * 1024 * 1024

    Default cap on the size of an Overpass response (16 MiB).

    The cap bounds the memory of decoding the body as well: parsed JSON takes about 6 times its size for building payloads and up to 25 times for a hostile body of empty objects (measured with tracemalloc), i.e. at most about 0.4 GiB. The largest payload of the AP1 catalogue (196 LV networks) is 3 MiB; pass a larger max_response_bytes for wide areas. Until the first 2026.11 consolidation the default was 64 MiB (up to 1.6 GiB parsed, audit L7).

    MAX_PAYLOAD_DEPTH module-attribute ¶

    MAX_PAYLOAD_DEPTH = 16

    Deepest container nesting accepted in an Overpass payload.

    An Overpass result nests at most seven levels (payload → elements → element → members → member → geometry → vertex). A body nested far deeper is not an Overpass result: up to about 10 000 levels it decodes and would reach the recursive pure-Python encoder of json.dump() in the cache write (RecursionError beyond about 1 000 levels, audit A2G-05); beyond that the decoder of Python 3.12 / 3.13 raises RecursionError; Python 3.14, whose recursion guard follows the C stack, may decode 100 000 levels (3.14.10 on the CI runner did, 3.14.6 did not). Every case becomes OverpassError right after decoding.

    MIN_OUTLINE_WIDTH_M module-attribute ¶

    MIN_OUTLINE_WIDTH_M = 0.001

    Mean width in m below which an outline encloses no area.

    The mean width \(w = 2A/P\) of a ring (twice its area over its perimeter, mean_width()) is the width of a long thin rectangle and 0 for identical or collinear vertices. An outline narrower than 1 mm on average is a digitising artefact, not a building: groundfield.geo.osm.parse_overpass_payload() skips it (BuildingFootprint.is_degenerate()). A mapped wall of 5 mm is kept (\(w \approx 5\) mm); generators widen its foundation (audit L5).

    def centroid_xy_m(self) -> Point2D:
    r"""Geometric centroid of the *exterior* ring in metres.

    Notes
    -----
    Holes are ignored — for the residential / commercial
    building shapes we care about, the moment shift caused by
    a hole is at most a few centimetres and irrelevant to the
    soil-spreading calculation. Implements

    .. math::

       C_x = \frac{1}{6A}\sum_{i=0}^{n-1}
             (x_i + x_{i+1})(x_i y_{i+1} - x_{i+1} y_i),

    analogously for :math:`C_y`.
    """
    ring = self.polygon_xy_m
    a = signed_area(ring)
    if a == 0.0:
        # Degenerate ring; fall back to the vertex mean.
        xs = [p[0] for p in ring]
        ys = [p[1] for p in ring]
        return (sum(xs) / len(xs), sum(ys) / len(ys))
    cx = cy = 0.0
    n = len(ring)
    for i in range(n):
        x0, y0 = ring[i]
        x1, y1 = ring[(i + 1) % n]
        cross = x0 * y1 - x1 * y0
        cx += (x0 + x1) * cross
        cy += (y0 + y1) * cross
    denom = 6.0 * a
    return (cx / denom, cy / denom)

    len_b = _math.hypot(x2 - x1, y2 - y1)
    angle_a = _axis_angle_deg(x1 - x0, y1 - y0)
    angle_b = _axis_angle_deg(x2 - x1, y2 - y1)
    if abs(len_a - len_b) <= _SQUARE_RTOL * max(len_a, len_b):
        # A square: both sides are "the long axis". Pick the axis
        # closest to +x (ties at ±45° go to +45°), so the result does
        # not depend on GEOS's vertex order (10.39).
        angle = min((angle_a, angle_b), key=lambda a: (abs(a), -a))
        dx = dy = max(len_a, len_b)
    elif len_a > len_b:
        angle, dx, dy = angle_a, len_a, len_b
    else:
        angle, dx, dy = angle_b, len_b, len_a
    cx = sum(c[0] for c in coords[:4]) / 4.0
    cy = sum(c[1] for c in coords[:4]) / 4.0
    return ((cx, cy), (dx, dy), angle)

    def mean_width(ring: Ring) -> float:
    r"""Mean width :math:`w = 2A/P` of a ring in m.

    Parameters
    ----------
    ring
        Vertex list in m (open or closed).

    Returns
    -------
    float
        Twice the absolute area :math:`A` over the perimeter :math:`P`:
        :math:`d_y` for a thin :math:`d_x \times d_y` rectangle
        (:math:`d_y \ll d_x`), :math:`d/2` for a square of side
        :math:`d`, and 0 for identical or collinear vertices (also for
        an empty ring).
    """
    n = len(ring)
    perimeter = 0.0
    for i in range(n):
        x0, y0 = ring[i]
        x1, y1 = ring[(i + 1) % n]
        perimeter += math.hypot(x1 - x0, y1 - y0)
    if perimeter <= 0.0:
        return 0.0
    return 2.0 * abs(signed_area(ring)) / perimeter

    payload: dict[str, Any],
    projector: Projector,
    *,
    min_area_m2: float = 0.0,
    exclude_building_tags: Optional[Collection[str]] = None,
) -> list[BuildingFootprint]:
    """Convert an Overpass JSON payload into projected
    :class:`BuildingFootprint` instances.

    Parameters
    ----------
    payload
        Overpass JSON as returned by :func:`query_buildings`.
    projector
        Projection from WGS84 to the local ENU frame. The same
        projector should be reused across all consumers of one
        payload to keep the metric coordinates consistent.
    min_area_m2
        Skip features whose footprint area is strictly below this
        threshold. ``0.0`` (the default) keeps every valid polygon;
        the placement layer may apply its own (higher) threshold via
        :class:`OsmBuildingPlacement.min_area_m2`.
    exclude_building_tags
        ``building=*`` values to drop (e.g.
        :data:`NON_SERVICE_BUILDING_TAGS`). ``None`` (default) keeps
        every element with a ``building`` tag — including garages,
        sheds and ``building=no``.

    Returns
    -------
    list[BuildingFootprint]
        Order matches the Overpass element order, which Overpass
        keeps deterministic for the same query.

    Raises
    ------
    OverpassError
        If the payload does not have the structure of an Overpass result
        or a vertex is not a finite WGS84 coordinate (see the module
        docstring). Elements whose geometry contains ``null`` vertices or
        that do not form a valid polygon are skipped: fewer than three
        vertices, or an outline without area (mean width below
        :data:`~groundfield.geo.footprint.MIN_OUTLINE_WIDTH_M`, i.e.
        identical or collinear vertices; audit A2G-06).

    Notes
    -----
    *Multipolygon relations* (``type=multipolygon``) are handled by
    walking the relation's ``members`` and treating each ``outer``
    way as an independent footprint with the ``inner`` ways of the
    *same* relation attached as holes. Relations without an
    ``outer`` member are skipped.
    """
    _check_payload(payload)
    elements = payload.get("elements", []) or []
    if isinstance(exclude_building_tags, str):
        exclude_building_tags = (exclude_building_tags,)
    excluded = frozenset(exclude_building_tags or ())
    by_id: dict[int, dict[str, Any]] = {
        e["id"]: e for e in elements if e.get("type") == "way" and "id" in e
    }
    out: list[BuildingFootprint] = []

    for el in elements:
        if (el.get("tags") or {}).get("building") in excluded:
            continue
        kind = el.get("type")
        if kind == "way":
            # Skip ways that belong to a multipolygon relation —
            # they would otherwise be emitted twice. Overpass does
            # not mark this directly, so for v1 we accept the
            # duplication; downstream consumers can de-duplicate
            # by ``osm_id`` if needed. The duplicate cost is small
            # because residential ways in OSM are usually standalone.
            ring_ll = _element_to_lat_lon_ring(el)
            if ring_ll is None or len(ring_ll) < 3:
                continue
            try:
                ring_xy: Ring = projector.ring_to_xy_m(ring_ll)
                fp = BuildingFootprint(
                    polygon_xy_m=ring_xy,
                    holes_xy_m=[],
                    levels=_levels_from_tags(el.get("tags") or {}),
                    building_use=(el.get("tags") or {}).get("building"),
                    osm_id=el.get("id"),
                    osm_tags=dict(el.get("tags") or {}),
                )
            except ValueError:
                continue
            if fp.is_degenerate() or fp.area_m2() < min_area_m2:
                continue
            out.append(fp)
        elif kind == "relation":
            tags = el.get("tags") or {}
            if tags.get("type") != "multipolygon":
                continue
            members = el.get("members") or []
            outers: list[list[tuple[float, float]]] = []
            inners: list[list[tuple[float, float]]] = []
            for m in members:
                if m.get("type") != "way":
                    continue
                role = m.get("role")
                ring_ll = _element_to_lat_lon_ring(m)
                if ring_ll is None:
                    # Try the referenced way from the same payload.
                    ref = by_id.get(m.get("ref"))
                    if ref is not None:
                        ring_ll = _element_to_lat_lon_ring(ref)
                if ring_ll is None or len(ring_ll) < 3:
                    continue
                if role == "outer":
                    outers.append(ring_ll)
                elif role == "inner":
                    inners.append(ring_ll)
            if not outers:
                continue
            # v1: emit each ``outer`` ring as a separate footprint
            # carrying the *full* list of inner holes. Hole-to-outer
            # assignment by winding-rule is deferred (rare in
            # residential OSM data; multipolygon buildings are
            # almost always Gewerbe-/Industriebauten with at most
            # one outer).
            for outer_ll in outers:
                try:
                    outer_xy = projector.ring_to_xy_m(outer_ll)
                    holes_xy = [projector.ring_to_xy_m(h) for h in inners]
                    fp = BuildingFootprint(
                        polygon_xy_m=outer_xy,
                        holes_xy_m=holes_xy,
                        levels=_levels_from_tags(tags),
                        building_use=tags.get("building"),
                        osm_id=el.get("id"),
                        osm_tags=dict(tags),
                    )
                except ValueError:
                    continue
                if fp.is_degenerate() or fp.area_m2() < min_area_m2:
                    continue
                out.append(fp)
        # Nodes are silently ignored: a building cannot be a node.
    return out

    def signed_area(ring: Ring) -> float:
    r"""Signed area of a polygon ring via the shoelace formula.

    Parameters
    ----------
    ring
        Vertex list. The ring may be open (last vertex != first); the
        shoelace formula closes it implicitly.

    Returns
    -------
    float
        Signed area in m². Positive for counter-clockwise rings,
        negative for clockwise rings, zero for degenerate rings.

    Notes
    -----
    Implements

    .. math::

       A \;=\; \tfrac{1}{2}\sum_{i=0}^{n-1}\bigl(x_i\,y_{i+1}\;-\;
                                                x_{i+1}\,y_i\bigr)

    with indices taken modulo *n*. The orientation convention used
    here (CCW positive) matches the right-hand rule with a
    z-axis pointing *out of the ground* in the local ENU frame.
    """
    n = len(ring)
    if n < 3:
        return 0.0
    s = 0.0
    for i in range(n):
        x0, y0 = ring[i]
        x1, y1 = ring[(i + 1) % n]
        s += x0 * y1 - x1 * y0
    return 0.5 * s
