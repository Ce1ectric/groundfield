    Backend registry¶

    Every numerical backend of Engine is a registered backend (groundfield.solver.registry, ADR-0014). A registration ties a name to its solve function, its declared capabilities, an optional options model for Engine.options, and flags for deprecated aliases, experimental status and the automatic forwarding by soil model. Engine.solve resolves the name, applies the forwarding, checks the capabilities against the world before any backend code runs, calls the solve function and fills the common metadata of the result.

    image_2layer two-layer line, point yes yes yes yes
    mom homogeneous, two-layer point yes (since 2026.11) yes yes yes
    mom_sommerfeld any number of layers point yes (since 2026.11) yes yes yes options: MomSommerfeldOptions
    fem any number of layers — yes (since 2026.11) yes (since 2026.11) yes (since 2026.11) yes (since 2026.11) experimental; axisymmetric model for coaxial rods and rings, 3-D model otherwise (fem3d extra); options: FemOptions

    Every built-in backend honours every conductor model (lumped, distributed, inductive, skin effect). Since its conforming model of 2026.11 (user decision Q37) fem runs the network of the shared pipeline like the integral backends: its axisymmetric model solves rods on one vertical axis and horizontal rings centred on it, its three-dimensional model (the optional fem3d extra) every other world, galvanic distributed conductors included (FemOptions.model). Up to then it solved distributed and inductive conductors as lumped resistive branches and rejected shells, junctions, two-terminal and voltage sources. The table is checked against the registry:

    import groundfield as gf
from groundfield.solver import get_backend

assert gf.available_backends() == ("image", "image_2layer", "mom", "mom_sommerfeld", "fem")
assert set(gf.available_backends(include_deprecated=True)) - set(gf.available_backends()) == {
    "cim", "bem", "image_nlayer"
}

caps = {name: get_backend(name).capabilities for name in gf.available_backends()}
assert caps["image"].kernels == {"line", "point"} and caps["mom"].kernels == {"point"}
assert caps["mom_sommerfeld"].soils == {"homogeneous", "two_layer", "multi_layer"}
assert caps["image"].concrete_shells and caps["mom"].concrete_shells
assert caps["mom_sommerfeld"].concrete_shells and caps["fem"].concrete_shells
assert caps["fem"].two_terminal_sources and caps["fem"].junctions
assert caps["fem"].conductors == {"lumped", "distributed", "inductive", "skin"}
assert all(caps[n].voltage_sources for n in gf.available_backends())
assert get_backend("fem").experimental
assert get_backend("cim").deprecated_alias_of == "image"
assert get_backend("bem").deprecated_alias_of == "mom"

    What the capability check does¶

    A world that a backend cannot represent raises BackendCapabilityError (a subclass of ValueError and NotImplementedError) naming the backends that can: an unsupported layer count, electrodes with a concrete-shell coefficient, junction nodes, voltage sources, or an explicitly requested kernel the backend does not have. Adjacent layers of equal resistivity count as one layer.

    A world that a backend solves with a documented simplification warns with BackendCapabilityWarning and solves: conductor models the backend reduces (no built-in backend since 2026.11), or a return_to terminal on a backend that returns the current through remote earth.

    Solving with a deprecated alias warns with DeprecationWarning; the first solve with an experimental backend in a process warns once with ExperimentalBackendWarning. Options for a backend that will not run warn with BackendOptionsWarning.

    Registering a backend¶

    register_backend(name, solve_fn, capabilities=..., options_model=...) adds a backend without changing Engine.solve; the solve function has the signature solve_fn(world, engine, **options) -> FieldResult. A registered name is accepted by Engine(backend=...) and listed by available_backends().

    API reference¶

    registry ¶

    Backend registry: names, capabilities, options and the solve contract.

    Every numerical backend of Engine is a registered backend. A registration ties a name to

    • a solve function solve_fn(world, engine, **options) -> FieldResult;
    • the capabilities of the backend (BackendCapabilities): which soil models, conductor models and source kinds it can represent;
    • an optional options model (a BackendOptions subclass) that validates the backend-specific settings in Engine.options; the validated options are passed to the solve function as keyword arguments;
    • optional aliases, a deprecated-alias target, an experimental flag and an auto-forwarding rule by soil model.

    Engine.solve resolves the requested name, applies the auto-forwarding, checks the capabilities against the world before any backend code runs, calls the solve function and fills the common metadata core of the result. Adding a backend therefore needs one register_backend() call and no change to Engine.solve.

    Capability checks

    A world that a backend cannot represent raises BackendCapabilityError naming the backends that can solve it:

    • the soil: homogeneous (one layer), two-layer, or n-layer (\(n \ge 3\)). Adjacent layers of equal resistivity are one layer physically, so a stack is acceptable to a backend that supports any layer count between the merged and the declared one (the check is conservative: it never rejects a world the backend could solve);
    • electrodes with a concrete-shell correction (ADR-0012);
    • leakage-free junction nodes (World.junctions) on a backend that does not build its nodal system through the shared pipeline;
    • a source kernel requested explicitly that the backend does not implement.

    A world that a backend solves with a documented simplification emits BackendCapabilityWarning and solves:

    • conductor models the backend reduces (no built-in backend since 2026.11; fem treated distributed conductors as lumped branches and ignored inductance and the skin effect up to its conforming model, user decision Q37);
    • sources with a return_to electrode on a backend that returns the current through remote earth instead.
    Backend options

    The validated options of the backend that runs are passed as keyword arguments. Settings that several backends and the post-solve layer share are common Engine fields, not backend options: segment_length, earth_inductive_model and the Tagg / Sunde image-series controls image_max_terms / image_series_tol (consumed by image_2layer, image_nlayer, mom, mom_sommerfeld on its delegated two-layer path and solve_mutual_*, and recorded in FieldResult.metadata["series"], from which FieldResult.potential() takes them for the post-solve field evaluation; the deprecated names cim and bem run image and mom). Their single documented defaults are DEFAULT_IMAGE_MAX_TERMS and DEFAULT_IMAGE_SERIES_TOL. image_far_field (the form of the far images of the line kernel, "quadrupole" or "point") is read by the image family in two-layer soil and solve_mutual_* and recorded in the same place.

    Deprecated aliases and experimental backends

    Solving with a deprecated alias emits a DeprecationWarning that names the replacement and the earliest removal (DEPRECATION_REMOVAL). The first solve with an experimental backend in a process emits ExperimentalBackendWarning once. Neither is emitted for the internal auto-forwarding.

    Since review pass 10 (10.76) cim and bem are pure deprecated aliases of image and mom (both assembled the same system as their target), image_nlayer is a deprecated name of the image auto-dispatch that keeps its own solve function, so the forwarding of image to it stays silent, and fem is experimental.

    DEFAULT_IMAGE_MAX_TERMS module-attribute ¶

    DEFAULT_IMAGE_MAX_TERMS = 300

    Default cap on the number of Tagg / Sunde image-series terms.

    One value for the engine, every layered backend and the post-solve field evaluation. The geometric tail bound |K|^(n+1)/(1-|K|) falls below the default tolerance after 277 terms for the AP1 corner soil rho_1 = 1000, rho_2 = 30 Ohm m (|K| = 0.9417), so the cap stays unused there.

    DEFAULT_IMAGE_SERIES_TOL module-attribute ¶

    DEFAULT_IMAGE_SERIES_TOL = 1e-06

    Default stop tolerance of the Tagg / Sunde image series.

    Summation ends when the geometric tail bound |K|^(n+1)/(1-|K|) falls below this value.

    BackendCapabilityError ¶

    Bases: ValueError, NotImplementedError

    The selected backend cannot represent the world.

    Raised by Engine.solve() before any backend code runs. The message names the missing capability and the registered backends that can solve the world. The backend functions raise it as well when they are called directly with a soil model they cannot solve (solve_image with a layered soil, solve_image_2layer with a homogeneous soil, solve_image_nlayer and solve_mom with three or more distinct layers), and so does the concrete-shell guard of the backends without the shell correction: one error type for one situation (audit A1-08). TypeError is left for a world.soil that is no soil model at all.

    Subclasses both ValueError and NotImplementedError, the types image_nlayer, cim, bem and the concrete-shell guard raised for the same situations in 0.15.0. Changed in 2026.11: image_2layer (homogeneous soil, layer stack) and mom (three or more layers) raised TypeError, which does not catch this error; catch BackendCapabilityError (or ValueError).

    def forward_target(self, soil_kind: str) -> str | None:
    """Backend the call is forwarded to for a soil model kind, if any."""

    def resolve_solve_fn(self) -> SolveFunction:
    """Return the callable solve function (imports lazy references).

    Returns
    -------
    Callable
        ``solve_fn(world, engine, **options) -> FieldResult``.

    Raises
    ------
    TypeError
        For a pure alias, which has no solve function of its own.
    """
    fn = self.solve_fn
    if fn is None:
        raise TypeError(f"Backend '{self.name}' is a pure alias.")
    if isinstance(fn, str):
        module_name, _, attr = fn.partition(":")
        return getattr(importlib.import_module(module_name), attr)
    return fn

    FemOptions ¶

    Bases: BackendOptions

    Mesh, extrapolation and truncation controls of the fem backend.

    Forwarded to groundfield.solver.fem.solve_fem(). The defaults reproduce the backend's own signature defaults. Since 2026.11 fem is a conforming finite-element model (user decision Q37): axisymmetric for rods on one axis and rings around it, three-dimensional for every other world (model, source_radius, growth, concrete_resistivity, max_nodes_3d, max_ports_3d; the optional fem3d extra).     def check_capabilities(
    resolved: ResolvedBackend,
    world: World,
    *,
    kernel: str | None = None,
    kernel_explicit: bool = False,
) -> None:
    """Check that the resolved backend can represent ``world``.

    Parameters
    ----------
    resolved
        Outcome of :func:`resolve_backend`.
    world
        World to be solved.
    kernel
        Source kernel requested by the engine, if the engine has one.
    kernel_explicit
        Whether the kernel was set explicitly (a default kernel that the
        backend does not implement is replaced by the backend's own).

    Raises
    ------
    BackendCapabilityError
        If the backend cannot represent the world.

    Warns
    -----
    BackendCapabilityWarning
        If the backend solves the world with a documented
        simplification (reduced conductor model, ignored
        ``return_to``).
    """
    spec = resolved.spec
    caps = _capabilities(spec)
    label = f"'{resolved.requested}'"
    if resolved.requested != spec.name:
        label += f" (running '{spec.name}')"
    problems = _hard_problems(spec, world, kernel, kernel_explicit)
    if problems:
        capable = _capable_backends(world, kernel, kernel_explicit)
        alternatives = (
            f"Backends that can: {', '.join(capable)}."
            if capable
            else "No registered backend supports this combination."
        )
        raise BackendCapabilityError(
            f"Backend {label} cannot solve this world: "
            f"{'; '.join(problems)}. {alternatives}"
        )

    reduced = sorted(_conductor_features(world) - caps.conductors)
    if reduced:
        able = [
            f"'{n}'"
            for n in available_backends()
            if set(reduced) <= _capabilities(_REGISTRY[n]).conductors
        ]
        dc = (
            " at their DC resistance (the skin effect of resistance_model="
            "'skin' is ignored)"
            if "skin" in reduced
            else ""
        )
        warn_external(
            f"Backend '{spec.name}' does not implement the {', '.join(reduced)} "
            "conductor model(s) of this world and solves them as lumped, "
            f"purely resistive branches{dc}. Backends that implement them: "
            f"{', '.join(able)}.",
            BackendCapabilityWarning,
        )
    two_terminal = [s.name for s in world.sources if getattr(s, "return_to", None)]
    if two_terminal and not caps.two_terminal_sources:
        warn_external(
            f"Backend '{spec.name}' ignores Source.return_to (source(s) "
            f"{two_terminal}): the current returns through remote earth, not "
            "through the return electrode.",
            BackendCapabilityWarning,
        )

    """Kernel a backend uses when the engine requests ``requested``.

    Parameters
    ----------

        Record of the backend that runs.
    requested

    def register_backend(
    name: str,
    solve_fn: SolveFunction | str | None,
    *,
    capabilities: BackendCapabilities | None = None,
    options_model: type[BackendOptions] | None = None,
    aliases: Iterable[str] = (),
    deprecated_alias_of: str | None = None,
    experimental: bool = False,
    forward: Mapping[str, str] | None = None,
    summary: str = "",
    replace: bool = False,
) -> BackendSpec:
    """Register a backend name.

    Parameters
    ----------
    name
        Backend name as used in ``Engine(backend=name)``.
    solve_fn
        ``solve_fn(world, engine, **options) -> FieldResult``, or a lazy
        ``"package.module:function"`` reference. ``None`` registers a
        pure deprecated alias that runs ``deprecated_alias_of``.
    capabilities
        What the backend can represent. Required unless ``solve_fn`` is
        ``None`` (a pure alias inherits its target's capabilities).
    options_model
        :class:`BackendOptions` subclass for ``Engine.options[name]``.
        Its fields must be keyword arguments of ``solve_fn``.
    aliases
        Further accepted names, resolved without a warning.
    deprecated_alias_of
        Registered replacement name. Solving with ``name`` then emits a
        :class:`DeprecationWarning` naming the replacement and
        :data:`DEPRECATION_REMOVAL`. With a ``solve_fn`` the old
        implementation keeps running; without, the replacement runs.
    experimental
        Emit :class:`ExperimentalBackendWarning` on the first solve in a
        process.
    forward
        Auto-forwarding by soil model kind, e.g. ``{"two_layer":
        "image_2layer"}``. Targets are resolved at solve time.
    summary
        One-line description.
    replace
        Allow replacing an existing registration of ``name``; the name
        keeps its position in :func:`available_backends`.

    Returns
    -------
    BackendSpec
        The stored registration record.

    Raises
    ------
    ValueError
        If the name is taken (and ``replace`` is false), the alias
        target is unknown or itself deprecated, or the arguments are
        inconsistent.
    """
    if not isinstance(name, str) or not name or name != name.strip():
        raise ValueError(f"Backend name must be a non-empty string, got {name!r}.")
    alias_names = tuple(aliases)
    taken = [n for n in (name, *alias_names) if n in _REGISTRY or n in _ALIASES]
    if replace and name in _REGISTRY:
        own = {name, *_REGISTRY[name].aliases}
        taken = [n for n in taken if n not in own]
    if taken:
        raise ValueError(
            f"Backend name(s) {taken} already registered; pass replace=True "
            "to replace a registration."
        )
    if deprecated_alias_of is not None:
        target = _REGISTRY.get(deprecated_alias_of)
        if target is None:
            raise ValueError(
                f"deprecated_alias_of={deprecated_alias_of!r} is not a "
                "registered backend."
            )
        if target.deprecated_alias_of is not None:
            raise ValueError(
                f"Backend '{deprecated_alias_of}' is itself deprecated; "
                "point the alias at its replacement."
            )
    if solve_fn is None:
        if deprecated_alias_of is None:
            raise ValueError("solve_fn=None is only allowed for a deprecated alias.")
        if capabilities is not None or options_model is not None or forward:
            raise ValueError(
                "A pure deprecated alias inherits capabilities, options and "
                "forwarding from its target; do not pass them."
            )
    elif capabilities is None:
        raise ValueError(f"Backend '{name}' needs capabilities.")
    if options_model is not None and not (
        isinstance(options_model, type) and issubclass(options_model, BackendOptions)
    ):
        raise TypeError("options_model must be a BackendOptions subclass.")
    forward_pairs = tuple((forward or {}).items())
    bad_kinds = sorted({k for k, _ in forward_pairs} - set(_SOIL_KINDS))
    if bad_kinds:
        raise ValueError(f"forward: unknown soil model kind(s) {bad_kinds}.")

    if deprecated_alias_of is not None:
        dependants = [
            s.name for s in _REGISTRY.values() if s.deprecated_alias_of == name
        ]
        if dependants:
            raise ValueError(
                f"Backend(s) {dependants} are deprecated aliases of '{name}'; it "
                "cannot become a deprecated alias itself."
            )
    if replace and name in _REGISTRY:
        # Re-assigning the key below keeps the registration order.
        for alias in _REGISTRY[name].aliases:
            _ALIASES.pop(alias, None)
        _EXPERIMENTAL_WARNED.discard(name)
    spec = BackendSpec(
        name=name,
        solve_fn=solve_fn,
        capabilities=capabilities,
        options_model=options_model,
        aliases=alias_names,
        deprecated_alias_of=deprecated_alias_of,
        experimental=bool(experimental),
        forward=forward_pairs,
        summary=summary,
    )
    _REGISTRY[name] = spec
    for alias in alias_names:
        _ALIASES[alias] = name
    return spec

    def validate_options_entry(key: str, value: Any) -> tuple[str, BackendOptions]:
    """Validate one ``Engine.options`` entry.

    Parameters
    ----------
    key
        Backend name or alias.
    value
        Options model instance or mapping of option values.

    Returns
    -------
    tuple
        ``(canonical backend name, options model instance)``.

    Raises
    ------
    ValueError
        For an unknown backend, a backend without options, an unknown
        option name (with a suggestion) or a wrong value type.

    if model is None:
        raise ValueError(
            f"Backend '{canonical}' has no backend-specific options. Settings "
            "shared by several backends are Engine fields: segment_length, "
            "earth_inductive_model, image_max_terms, image_series_tol."
        )

        return canonical, value

        raise ValueError(
            f"Engine.options['{canonical}'] must be a {model.__name__}, got "
            f"{type(value).__name__}."
        )

        raise ValueError(
            f"Engine.options['{canonical}'] must be a {model.__name__} or a "
            f"mapping, got {type(value).__name__}."

    if unknown:
        hints = []

            f"Valid options: {_describe_options(model)}."
