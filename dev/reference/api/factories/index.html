    Factories¶

    The create_* functions are the notebook-friendly way to build a model: each one constructs an object, registers it in the World and returns it. They are thin wrappers around the model classes (gf.RodElectrode(...) plus world.add_electrode(...) is equivalent), with two additions: the parameters of every electrode kind are typed (IDE completion, type-checker errors for a misspelled kind or keyword), and unknown names raise with the closest valid name ("did you mean …?").

    Factory Creates Physical meaning
    create_world(soil=...) World container of the physical model; the soil is the conducting half-space
    create_electrode(world, kind, ...) electrode (rod, ring, strip, polyline, star, mesh, grid_mesh) metal in contact with the soil; leaks current
    create_conductor(world, start=, end=, ...) Conductor connection between two nodes: ideal, lumped resistance, or a distributed line with resistance, inductance and optional leakage
    create_junction(world, position=) Junction node without soil contact (cable joint, instrument terminal)
    create_source(world, attached_to=, ...) CurrentSource impressed current between a node and remote earth or a second node (return_to)
    create_engine(...) Engine the numerics: backend, frequencies, segment length, kernel, earth-return model
    run_simulation(world, engine) FieldResult the same as world.solve(engine) and engine.solve(world)

    Mathematical and physical context¶

    The factories assemble the boundary-value problem that every backend solves: Laplace's equation \(\nabla\cdot(\sigma\nabla\varphi) = 0\) in the layered soil (soil), the electrode surfaces as equipotential boundaries per galvanic cluster (create_electrode), Kirchhoff's laws for the conductor network between the nodes (create_conductor, create_junction), and the impressed currents as the right-hand side (create_source). The Engine decides how the problem is discretised and solved; the World holds only physics and can be solved by several engines for a cross-check.

    Coordinates are \((x, y, z)\) in metres with \(z\) the depth below the soil surface (positive downwards); every other quantity is in SI units (see Units and conventions).

    Example¶

    import groundfield as gf

world = gf.create_world(soil=gf.HomogeneousSoil(rho=100.0))
rod = gf.create_electrode(world, "rod", name="g1", position=(0.0, 0.0, 0.0), length=1.5)
ring = gf.create_electrode(world, "ring", name="g2", center=(10.0, 0.0, 0.8), radius=2.0)
joint = gf.create_junction(world, name="J1", position=(5.0, 0.0, 0.7))  # cable joint
gf.create_conductor(world, name="l1", start=rod, end=joint, cross_section=50e-6)
gf.create_conductor(world, name="l2", start=joint, end=ring, cross_section=50e-6)
gf.create_source(world, name="s1", attached_to="g1", magnitude=10.0)
engine = gf.create_engine(backend="image", frequencies=[50.0, 150.0])
result = gf.run_simulation(world, engine)

assert type(ring).__name__ == "RingElectrode"
assert len(result.input_impedance("s1")) == 2   # one value per frequency

    create_electrode(world, "rnig", ...) raises ValueError: Unknown electrode kind 'rnig'. Did you mean 'ring'?; a keyword that the chosen kind does not take raises TypeError with the list of valid keywords. A junction that no conductor connects to an electrode has no defined potential and is rejected when the world is solved.

    API reference¶

    api ¶

    Top-level factory functions.

    This module provides the convenient, notebook-friendly API of groundfield. Instead of instantiating each class manually, the caller writes:

    import groundfield as gf world = gf.create_world(soil=gf.HomogeneousSoil(rho=100.0)) rod = gf.create_electrode(world, "rod", name="g1", ... position=(0.0, 0.0, 0.0), length=1.5) ring = gf.create_electrode(world, "ring", name="g2", ... center=(10.0, 0.0, 0.8), radius=2.0) conn = gf.create_conductor(world, name="l1", start=rod, end=ring, ... conductor_type="bare_copper") src = gf.create_source(world, name="s1", attached_to="g1", ... magnitude=10.0) j = gf.create_junction(world, name="J1", position=(10.0, 0.0, 0.5)) eng = gf.create_engine(backend="image", frequencies=[50.0]) result = gf.run_simulation(world, eng) # or world.solve(eng)

    Conventions
    • Every create_* function registers the new object in the World and returns it.
    • start / end of a conductor may be electrodes, junctions, their names, or coordinate tuples.
    • Names are auto-generated when omitted (electrode_0, conductor_0, source_0, junction_0).
    • Coordinates are in metres with z pointing downwards (z > 0 is in the soil).
    Static typing

    create_electrode() has one @overload per electrode kind, so an IDE shows the parameters of the chosen kind and a type checker reports a misspelled kind or keyword and infers the concrete return type (create_electrode(w, "ring", ...) is a RingElectrode). The string options are Literal types (ElectrodeKind, SourceKind, KernelKind, and Backend, EarthInductiveModel, ConductorType, SoilCoupling, InductanceModel where they are defined). A kind chosen at run time (a plain str) needs a typing.cast to ElectrodeKind — or build the class directly (gf.RodElectrode(...) plus world.add_electrode). At run time, an unknown kind, keyword or electrode name raises with the closest valid name ("did you mean …?").

    ElectrodeKind module-attribute ¶

    ElectrodeKind: TypeAlias = Literal['rod', 'ring', 'strip', 'polyline', 'star', 'mesh', 'grid_mesh']

    Electrode kinds accepted by create_electrode().

    "rod", "ring", "strip", "polyline", "star", "mesh" and "grid_mesh" create a RodElectrode, RingElectrode, StripElectrode, PolylineElectrode, StarElectrode, MeshElectrode and GridMeshElectrode.

    SourceKind module-attribute ¶

    SourceKind: TypeAlias = Literal['current', 'voltage']

    Source kinds accepted by create_source().

    "current" creates a CurrentSource (impressed current), "voltage" a VoltageSource (impressed voltage, ideal or behind an internal impedance).

    KernelKind module-attribute ¶

    KernelKind: TypeAlias = Literal['point', 'line']

    Source kernels accepted by create_engine().

    The kernel is used for the reaction matrix and the field evaluation: "point" (one point source per segment) or "line" (the exact uniform line source per segment). kernel=None leaves the choice to the backend.

    PointLike module-attribute ¶

    PointLike: TypeAlias = Sequence[float] | npt.NDArray[Any]

    A point (x, y, z) in m: a tuple, a list or a numpy array.

    ConductorEnd module-attribute ¶

    ConductorEnd: TypeAlias = PointLike | Electrode | Junction | str

    One end of a conductor in create_conductor().

    An electrode or junction, the name of a registered electrode or junction, or a point (x, y, z) in m.

    def create_world(
    *,
    name: str = "world",
    soil: SoilModel | None = None,
    boundary: BoundaryConditions | None = None,

    """Create an empty :class:`World`.

    Parameters
    ----------
    name
        Human-readable name (used in logs and result metadata).
    soil
        Optional pre-built soil model. Can also be set later via
        ``world.soil = ...``.
    boundary
        Optional pre-built boundary configuration. No backend reads it
        (see :class:`~groundfield.BoundaryConditions`).

    Returns
    -------
    World
        The new, empty world.
    """
    kwargs: dict[str, Any] = {"name": name}
    if soil is not None:
        kwargs["soil"] = soil
    if boundary is not None:
        kwargs["boundary"] = boundary
    return World(**kwargs)

    def create_electrode(
    world: World,
    kind: str = "rod",
    *,
    name: str | None = None,
    **params: Any,
) -> _ElectrodeBase:
    """Create an electrode and register it with ``world``.

    Parameters
    ----------
    world
        Target world that will own the new electrode.
    kind
        Geometry type (:data:`ElectrodeKind`). The keyword parameters of
        each kind (lengths in m, angles in degrees, ``z > 0`` in the
        soil; ``wire_radius`` defaults to 0.005 m and the concrete-shell
        coefficient ``concrete_shell_coefficient_ohm_m`` (Ω·m, ADR-0012)
        to 0 for every kind):

        - ``"rod"`` — ``position`` (top end), ``length``.
        - ``"ring"`` — ``center``, ``radius``.
        - ``"strip"`` — ``start``, ``end``.
        - ``"polyline"`` — ``vertices``, ``closed`` (default ``True``).
        - ``"star"`` — ``center``, ``n_arms``, ``arm_length``,
          ``orientation_deg`` (default 0).
        - ``"mesh"`` — ``corner``, ``size`` ``(x, y)``, ``spacing``
          (default 1 m).
        - ``"grid_mesh"`` — ``corner``, ``size`` ``(x, y)``, ``n_x``,
          ``n_y``.

        See :mod:`groundfield.geometry.electrodes` for the geometry of
        each class.
    name
        Optional unique name. Auto-generated (``electrode_<n>``) when
        ``None``.
    **params
        The parameters of ``kind`` listed above.

    Returns
    -------
    Electrode
        The registered electrode, of the class that belongs to ``kind``
        (:class:`RodElectrode` for ``"rod"``, :class:`RingElectrode` for
        ``"ring"``, …); type checkers infer the concrete class from the
        overloads.

    Raises
    ------
    ValueError
        Unknown ``kind`` (with the closest valid kind), or a parameter
        value the electrode model rejects.
    TypeError
        A keyword that ``kind`` does not have (with the closest valid
        keyword, or the kinds that do have it).
    """
    cls = _ELECTRODE_CLASSES.get(kind)
    if cls is None:
        raise ValueError(
            f"Unknown electrode kind {kind!r}."
            f"{did_you_mean(str(kind), _ELECTRODE_CLASSES)} "
            f"Valid kinds: {', '.join(repr(k) for k in _ELECTRODE_CLASSES)}."
        )
    allowed = _parameters_of(cls)
    unknown = [key for key in params if key not in allowed]
    if unknown:
        raise TypeError(_unknown_keyword_message(kind, unknown, allowed))
    if name is None:
        name = _auto_name(world, "electrodes", "electrode")
    electrode = cls(name=name, **params)
    world.add_electrode(electrode)
    return electrode

    def create_conductor(
    world: World,
    *,
    start: ConductorEnd,
    end: ConductorEnd,
    name: str | None = None,
    conductor_type: ConductorType = "generic",
    wire_radius: float = 0.005,
    resistivity: float = 1.68e-8,
    cross_section: float | Literal["from_radius"] | None = None,
    discretize_segment_length: float | None = None,
    coupling_to_soil: SoilCoupling = "isolated",
    inductance_model: InductanceModel | None = None,
    lumped_series_resistance_ohm: float | None = None,
    resistance_model: ResistanceModel = "dc",
) -> Conductor:
    """Create a conductor and register it with ``world``.

    Parameters
    ----------
    world
        Target world.
    start, end
        Start and end point. Each may be an electrode or a junction
        (:func:`create_junction`), the name of a registered electrode or
        junction, or a coordinate tuple ``(x, y, z)`` in m. A conductor
        joins the network only if both ends are nodes.
    name
        Optional unique name. Auto-generated (``conductor_<n>``) when
        ``None``.
    conductor_type
        Conductor type (:data:`~groundfield.conductors.conductor.ConductorType`).
    wire_radius
        Wire radius in m.
    resistivity
        Material resistivity of the conductor in Ω·m (default: copper,
        1.68e-8 Ω·m).
    cross_section
        Conductor cross section in $\\mathrm{m}^2$. ``None`` (default)
        keeps the historic ideal-galvanic-short behaviour: both end
        electrodes are fused into one cluster with a common potential.
        A finite value activates the finite-impedance branch model
        with $R_\\text{ser} = \\rho_\\text{mat}\\, L / A$. The string
        ``"from_radius"`` resolves to $\\pi\\, r_\\text{wire}^2$.
    discretize_segment_length
        Maximum sub-segment length in m for the distributed-conductor
        model (see ADR-0003). ``None`` (default) keeps the conductor
        lumped (single segment, leakage only at the end electrodes). A
        galvanic conductor leaks along its length also with a single
        sub-piece (a value at least the conductor length).
    coupling_to_soil
        ``"isolated"`` (default) — the conductor does not exchange
        current with the soil along its length. ``"galvanic"`` — every
        segment leaks current into the soil. For an insulated cable
        keep ``"isolated"``; for buried bare copper or an exposed
        shield use ``"galvanic"``.
    inductance_model
        ``None`` (default) keeps the longitudinal-branch impedance
        purely resistive (DC behaviour). ``"neumann"`` activates the
        Neumann self- and mutual-inductance integral between the
        branches of every inductive conductor — the segments of a
        distributed conductor, or one branch from start to end for a
        lumped one (ADR-0004, review pass 10, 10.24) — and the system
        becomes frequency-dependent and complex per frequency.
    lumped_series_resistance_ohm
        Optional additional lumped series resistance in Ω.
    resistance_model
        ``"dc"`` (default): the series resistance is the DC value.
        ``"skin"``: the AC resistance of a solid round wire with skin
        effect, opt-in (review pass 10, 10.37); needs a finite
        ``cross_section`` (see :class:`~groundfield.conductors.Conductor`).

    Returns
    -------
    Conductor
        The registered conductor.

    Raises
    ------
    KeyError
        ``start`` or ``end`` names an electrode or junction that does
        not exist (with the closest names).
    """
    if name is None:

    ----------

    Parameters
    ----------
    world
        Target world.
    attached_to
        Node the source feeds: an electrode or a junction
        (:func:`create_junction`), or its name.
    name

    cls = _SOURCE_CLASSES.get(kind)
    if cls is None:
        raise ValueError(
            f"Unknown source kind {kind!r}.{did_you_mean(str(kind), _SOURCE_CLASSES)} "
            f"Valid kinds: {', '.join(repr(k) for k in _SOURCE_CLASSES)}."

        magnitude=magnitude,
        phase_deg=phase_deg,
        **impedance,
    )

    return src

    def run_simulation(world: World, engine: Engine) -> FieldResult:
    """Solve ``world`` with ``engine``; identical to ``world.solve(engine)``.

    The call goes through :meth:`World.solve` and therefore has exactly
    its semantics, including the source snapshot: the world's sources
    are restored after the solve even if a backend changes them in
    flight, and the handles returned by :func:`create_source` stay
    attached to the world.

    Parameters
    ----------
    world
        The world to solve.
    engine
        The engine configuration.

    Returns
    -------
    FieldResult
        The solution.
    """
    return world.solve(engine)
