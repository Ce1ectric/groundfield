    References¶

    groundfield.references collects the closed-form results of the classical literature that the numerical backends are validated against. They are independent of the solver code: every engine and every new geometry is checked against at least one of them (see the validation page).

    Mathematical and physical context¶

    All formulas assume the same physics as the solver — quasi-static fields, linear isotropic soil — but in idealised geometries where the boundary-value problem has a closed or semi-closed solution. Two examples:

    • Driven rod of length \(L\) and radius \(a\), top at the surface of a homogeneous soil (Dwight 1936): \(R = \dfrac{\rho}{2\pi L}\left(\ln\dfrac{4L}{a} - 1\right)\).
    • Buried conductor at depth \(d\) in two-layer soil (Pollaczek, Sunde): the self impedance per unit length is a spectral integral with the effective vertical wavenumber of the layered earth; it reduces to Carson's line impedance for \(\rho_1 = \rho_2\) and lies between the two homogeneous Carson values otherwise.

    Each reference states its own accuracy: Dwight's rod and ring formulas are asymptotic in \(a/L\) and accurate to well below 1 % for thin electrodes; Sverak's grid formula is an empirical estimate that IEEE 80 quotes to a few per cent for typical substation grids.

    Example¶

    import groundfield as gf
from groundfield.references import dwight1936, ieee80


def resistance(kind, **geometry):
    """Grounding resistance in Ω of one electrode in 100 Ω·m soil."""
    world = gf.create_world(soil=gf.HomogeneousSoil(rho=100.0))
    electrode = gf.create_electrode(world, kind, name="e", **geometry)
    gf.create_source(world, attached_to="e", magnitude=1.0)
    return gf.create_engine().solve(world).input_impedance()[0].real, electrode


R_rod, rod = resistance("rod", position=(0.0, 0.0, 0.0), length=3.0)        # 35.99 Ω
R_grid, grid = resistance(
    "grid_mesh", corner=(-10.0, -10.0, 0.5), size=(20.0, 20.0), n_x=5, n_y=5
)                                                                             # 2.31 Ω

R_dwight = dwight1936.rod(rho=100.0, length=3.0, radius=0.005)               # 35.99 Ω
R_sverak = ieee80.grid_resistance_sverak(
    rho=100.0, total_conductor_length=grid.total_length(), area=400.0, depth=0.5
)                                                                             # 2.54 Ω
assert abs(R_rod / R_dwight - 1) < 1e-3     # closed form: agreement to 0.01 %
assert abs(R_grid / R_sverak - 1) < 0.10    # empirical estimate: 9 % for this small grid

    API reference¶

    dwight1936 ¶

    Grounding resistances of simple geometries after Dwight (1936).

    Source

    Dwight, H. B.: Calculation of Resistances to Ground. Electrical Engineering / AIEE Transactions, Vol. 55, No. 12, December 1936, pp. 1319-1328 (Paper 36-129). In particular the summary Table I on p. 1325.

    Conventions
    • All lengths are given in metres (Dwight uses cm; the SI conversion is lossless because only dimensionless ratios and the prefactor \(\rho/(\dots\pi L)\) appear).
    • \(\rho\) is the resistivity of the homogeneous soil in \(\Omega\,\mathrm{m}\).
    • For buried electrodes Dwight's Table I uses \(s\) for the image distance, i.e. twice the burial depth: \(s = 2\,t\), where \(t\) is the depth of the centre of the electrode below the surface. The functions defined here take depth (= \(t\)) and convert internally to \(s = 2\,t\).
    • Wire parameters: a is the wire radius (not the diameter); for geometries that use the wire diameter \(d\) in Table I (the ring), the conversion d = 2*a applies.
    Range of validity

    All formulas assume homogeneous soil in the low-frequency (quasi-static) regime. Dwight quotes a few-percent accuracy for most expressions (Howe's average-potential method). The rod formula is within < 1 %; the star geometries within a few percent (Dwight 1936, p. 1324, "equations 23 to 26").

    Notes

    The functions are pure Python scalars (NumPy scalars also work). They are intentionally not vectorised — comparison tests need clarity, not performance.

    def buried_ring(
    rho: float, ring_diameter: float, wire_diameter: float, depth: float
) -> float:
    """Buried wire ring, Table I, Eq. (29).
    $$
    R = \\frac{\\rho}{2\\pi^2\\,D}\\,
        \\Bigl(\\ln\\tfrac{8D}{d} + \\ln\\tfrac{4D}{s}\\Bigr)
    $$
    Parameters
    ----------
    rho : float
        Resistivity of the homogeneous soil in Ω·m.
    ring_diameter : float
        Ring diameter $D$ in m.
    wire_diameter : float
        Wire diameter $d$ in m (i.e. ``2*radius``).
    depth : float
        Burial depth $t$ in m; $s = 2\\,t$.

    Returns
    -------
    float
        Grounding resistance in Ω.

    Notes
    -----
    Validity: $d \\ll s \\ll D$. Outside this regime the error
    grows quickly.
    """
    D = ring_diameter
    d = wire_diameter
    s = 2.0 * depth
    return (
        rho / (2.0 * math.pi**2 * D) * (math.log(8.0 * D / d) + math.log(4.0 * D / s))
    )

    def horizontal_round_plate(rho: float, radius: float, depth: float) -> float:
    """Horizontal round plate, Table I (Eqs. 32 + 36).
    $$
    R = \\frac{\\rho}{8 a} +
        \\frac{\\rho}{4\\pi s}\\,
          \\Bigl(1 - \\tfrac{7 a^2}{12 s^2}
                    + \\tfrac{33 a^4}{40 s^4}\\Bigr)
    $$
    Assumption: plate plane parallel to the soil surface; image
    distance $s = 2\\,t$ ≫ plate radius $a$ for the series
    to converge.

    Parameters
    ----------
    rho : float
        Resistivity of the homogeneous soil in Ω·m.
    radius : float
        Plate radius $a$ in m.
    depth : float
        Burial depth $t$ of the plate in m; internally $s = 2t$.

    Returns
    -------
    float
        Grounding resistance in Ω.
    """
    s = 2.0 * depth
    a = radius
    R_self = rho / (8.0 * a)
    R_image = (
        rho
        / (4.0 * math.pi * s)
        * (1.0 - 7.0 * a**2 / (12.0 * s**2) + 33.0 * a**4 / (40.0 * s**4))
    )
    return R_self + R_image

    rho: float,
    length: float,
    width: float,
    thickness: float,
    depth: float,
) -> float:
    """Buried strip electrode (rectangular cross-section), Table I, Eq. (31).
    $$
    R = \\frac{\\rho}{4\\pi L}\\,
        \\Bigl(\\ln\\tfrac{4L}{a} + \\tfrac{a^2 - \\pi a b}{2(a+b)^2}
               + \\ln\\tfrac{4L}{s} - 1 + \\tfrac{s}{2L}
               - \\tfrac{s^2}{16 L^2}
               + \\tfrac{s^4}{512 L^4}\\Bigr)
    $$
    Parameters
    ----------
    rho : float
        Resistivity of the homogeneous soil in Ω·m.
    length : float
        Half the strip length $L$ in m (total length ``2*L``).
    width : float
        Strip width $a$ in m.
    thickness : float
        Strip thickness $b$ in m. Validity: $b < a/8$.
    depth : float
        Burial depth $t$ in m; $s = 2\\,t$.

    Returns
    -------
    float
        Grounding resistance in Ω.

    Raises
    ------
    ValueError
        If ``thickness`` is not smaller than ``width / 8`` (the
        precondition of Dwight's Eq. 30).

    Notes
    -----
    The constant is $-1$, **not** the $-2$ of the round-wire form
    :func:`horizontal_wire`, because the strip bracket already carries
    the cross-section term $(a^2 - \\pi a b)/(2(a+b)^2) \\to 1/2$ as
    $b \\to 0$:

    $$
    \\underbrace{\\ln\\tfrac{4L}{a} + \\tfrac12
                 + \\ln\\tfrac{4L}{s} - 1}_{\\text{strip of width } a}
    \\;=\\;
    \\underbrace{\\ln\\tfrac{4L}{a} + \\tfrac32
                 + \\ln\\tfrac{4L}{s} - 2}_{\\text{round wire of radius }
                                            a\\,e^{-3/2}},
    $$

    i.e. a vanishingly thin strip of width $a$ *is* the round wire of
    radius equal to the strip's self-GMD $a\\,e^{-3/2}$. That is the
    consistency check: for $b \\to 0$ this function equals
    ``horizontal_wire(rho, L, a*exp(-1.5), depth)`` up to the $O(b/a)$
    residual of the cross-section term (8.6e-6 relative at
    $a = 30$ mm, $b = 1$ µm; 8.6e-9 at $b = 1$ nm). Corrected in
    0.15.0 (finding F37): the $-2$ used up to 0.14.1 made the bracket
    one full unit too small, i.e. $R$ low by $\\rho/(4\\pi L)$ —
    10 % at $a = 30$ mm, 13 % at $a = 300$ mm for $L = 10$ m,
    $t = 0.8$ m.
    """
    L, a, b = length, width, thickness
    if b >= a / 8.0:
        raise ValueError(
            "horizontal_strip: precondition b < a/8 violated "
            f"(a={a}, b={b}). See Dwight 1936, Eq. 30."
        )
    s = 2.0 * depth
    inner = (
        math.log(4.0 * L / a)
        + (a**2 - math.pi * a * b) / (2.0 * (a + b) ** 2)
        + math.log(4.0 * L / s)
        - 1.0
        + s / (2.0 * L)
        - s**2 / (16.0 * L**2)
        + s**4 / (512.0 * L**4)
    )
    return rho / (4.0 * math.pi * L) * inner

        Resistivity of the homogeneous soil in Ω·m.
    length : float

    radius : float
        Wire radius $a$ in m.

    oeding ¶

    Inductance formulas from Oeding/Oswald 2016, Elektrische Kraftwerke und Netze, chapter 9 (overhead lines) and chapter 16 (cables).

    This module collects the per-unit-length loop self- and mutual inductance formulas that the standard German power-engineering reference uses to characterise long, parallel conductor systems. They are the textbook results that the segment-based Neumann implementation in groundfield.coupling.inductance must reproduce in the limit \(\ell \to \infty\).

    All formulas assume:

    • straight, parallel conductors,
    • conductor radius small compared to inter-conductor distance,

    earth_return ¶

    Carson earth-return line-impedance reference (per unit length).

    Closed-form series impedance of a conductor with earth return, as derived by Carson (1926) and reproduced in every power-system textbook. It is the engineering-level (Ω/km) companion to the dimensionless Carson integral tabulated in groundfield.references.carson, and the reference against which the assembled Sommerfeld/Pollaczek earth-return stack (earth_inductive_model="sommerfeld") is benchmarked in tests/test_earth_return_benchmark.py and notebooks/45_earth_return_line_impedance.ipynb.

    Mathematical background

    For a thin conductor of geometric mean radius \(\mathrm{GMR}\) above or below a homogeneous earth of resistivity \(\rho\), carrying a current that returns through the earth, Carson's series impedance per unit length at angular frequency \(\omega = 2\pi f\) is

    \[ Z'_\text{self} = \underbrace{\frac{\omega\mu_0}{8}}_{R'_\text{earth}} + j\,\frac{\omega\mu_0}{2\pi}\,\ln\!\frac{D_e}{\mathrm{GMR}}, \qquad Z'_\text{mutual} = \frac{\omega\mu_0}{8} + j\,\frac{\omega\mu_0}{2\pi}\,\ln\!\frac{D_e}{d_{ij}}, \]

    where \(d_{ij}\) is the conductor–conductor separation and

    \[ D_e = 658.87\,\sqrt{\rho / f}\ \text{[m]} \]

    is Carson's equivalent earth-return depth — the depth of the fictitious return conductor that reproduces the earth's inductive effect. Two features carry the physics:

    • the earth-return resistance \(R'_\text{earth} = \omega\mu_0/8\) (\(\approx 0.0493\) Ω/km at 50 Hz) is independent of the soil resistivity — it is the loss of the return current spreading through the earth;
    • the equivalent depth \(D_e \propto \sqrt{\rho/f}\) shrinks with frequency and grows with soil resistivity — a more resistive or lower-frequency earth lets the return current spread deeper and wider. The earth-return reactance \(X' = (\omega\mu_0/2\pi)\ln(D_e/\mathrm{GMR})\) therefore increases with soil resistivity and also increases with frequency: the \(\omega\) prefactor dominates the shrinking logarithm, so \(X'\) rises almost linearly with \(f\) (1000 Ω·m, GMR = 7 mm: 0.814 mΩ/m at 50 Hz → 14.39 mΩ/m at 1 kHz, a 17.7× rise over a 20× frequency step).

    Internal-inductance convention (review pass 10, finding 10.46). The formulas here are external to the conductor for a given \(\mathrm{GMR}\). The assembled inductive stack of groundfield adds the DC internal inductance \(\mu_0/(8\pi)\) per metre of a solid round conductor to every self term by default (groundfield.coupling.inductance.thin_wire_self_inductance(), include_internal=True), so a like-for-like comparison uses \(\mathrm{GMR} = a\,e^{-1/4} = 0.7788\,a\); with GMR = a the stack sits 2.0–2.5 % above Carson's reactance (100 Ω·m at 50 Hz to 30 Ω·m at 1 kHz, 4 mm wire) for that reason alone. Use GMR = a together with include_internal=False. The frequency dependence of the internal impedance (skin effect) is groundfield.conductors.Conductor.internal_impedance_per_length().

        Series impedance :math:`R' + jX'` in Ω/m.
    """
    _check_positive(rho=rho, frequency=frequency, gmr=gmr)

    d_e = carson_equivalent_depth(rho, frequency)
    x = omega * MU_0 / (2.0 * math.pi) * math.log(d_e / gmr)
    return complex(r_earth, x)

    pollaczek ¶

    Layered (Pollaczek/Sunde) earth-return line impedance reference.

    The per-unit-length self and mutual impedances of conductors buried in a two-layer earth, as exact quasi-static spectral integrals. This is the layered, buried-conductor companion to groundfield.references.earth_return.carson_self_impedance(): where Carson gives the homogeneous equivalent-depth closed form, this gives the spectral integral over a stratified earth, and reduces to Pollaczek's homogeneous form for rho_1 == rho_2.

    It is the analytic per-unit-length quantity that the assembled Sommerfeld/Pollaczek stack (earth_inductive_model="sommerfeld") does not expose directly — the assembled stack builds a PEEC segment inductance matrix, from which a single per-unit-length line impedance cannot be read back without an ill-defined return-path assumption. This closed integral form therefore both (a) serves callers that need a frequency- and layer-dependent series impedance belag z'(f) (e.g. a reduced nodal network of a distribution earthing system) and (b) gives groundfield an independent per-unit-length reference against which the assembled stack's earth-return reactance can be benchmarked.

    Mathematical background

    A line current at depth \(h\) in a two-layer earth (layer 1 of thickness \(h_1\) and resistivity \(\rho_1\) over a half-space \(\rho_2\), air above) has the quasi-static vector potential

    \[ A(y, z) \propto K_0(\gamma_k R) + \int_0^\infty F(\lambda; z, h)\,\cos(\lambda y)\,d\lambda , \]

    with \(\gamma_k^2 = j\omega\mu_0/\rho_k\) of the conductor's layer and \(u_k = \sqrt{\lambda^2 + \gamma_k^2}\). The spectral amplitude \(F\) follows exactly from the continuity of \(A\) and \(\partial A/\partial z\) at the soil surface and at the layer interface (Tsiamitros et al. 2005, Eq. 8). For a conductor in layer 1, with \(r_0 = (u_1-\lambda)/(u_1+\lambda)\) and \(K = (u_1-u_2)/(u_1+u_2)\),

    \[ F = \frac{r_0 e^{-u_1(h+h')} + K e^{-u_1(2h_1-h-h')} + r_0 K\bigl[e^{-u_1(2h_1-h+h')} + e^{-u_1(2h_1+h-h')}\bigr]} {u_1\,\bigl(1 - r_0 K e^{-2u_1 h_1}\bigr)} , \]

    and the per-unit-length self impedance is

    \[ Z'_\text{self} = j\,\frac{\omega\mu_0}{2\pi}\left[ K_0(\gamma_1\,\mathrm{GMR}) + \int_0^\infty F(\lambda; h, h)\,d\lambda \right]. \]

    Conductors in layer 2 and pairs in different layers use the corresponding generalised-reflection and transmission amplitudes (see _two_layer_amplitude()). For \(\rho_1 = \rho_2\) the form reduces to the homogeneous Pollaczek integral \(K_0(\gamma\,\mathrm{GMR}) - K_0(2\gamma h) + 2\int_0^\infty e^{-2hu}/(\lambda+u)\,d\lambda\).

    Review pass 10 (finding 10.45) replaced two approximations of earlier releases:

    • the two-layer kernel used the surface wavenumber \(u_\text{eff}\) of the layered earth (Tagg/Sunde/Wait recursion, layered_effective_wavenumber()) in the buried exponent, \(e^{-2h u_\text{eff}}/(\lambda + u_\text{eff})\) — exact only for \(h \to 0\) or \(\rho_1 = \rho_2\); it missed the lower-interface term \(K e^{-2u_1(h_1-h)}\): \(R'\) −0.13…−0.5 % in band near an interface, −28.5 % at 1 MHz;
    • the head term was the small-argument form \(\ln(2h/\mathrm{GMR})\) of \(K_0(\gamma\,\mathrm{GMR}) - K_0(2\gamma h)\): \(R'\) −0.15 % (1 m) and −0.99 % (3 m) at 30 Ω·m, 1 kHz — more than the documented "< 0.05 %".

    Both are now exact at every frequency (quasi-static) for the same cost.

    Note the exponent: for a conductor buried in the earth the vertical decay of the reflected field is governed by \(u_1\), not by \(\lambda\). The Laplace kernel \(e^{-2h\lambda}\) is Carson's air kernel, valid only for a conductor above the interface; using it below the interface under-counts \(R'\) and inverts the sign of its depth dependence (fixed in 0.15.0, pass-9 F09).

    Internal-inductance convention. Like groundfield.references.earth_return, this returns the earth-return series impedance, external to the conductor, for the geometric mean radius gmr: pass gmr equal to the physical wire radius \(a\) for a pure external model, or \(a\,e^{-1/4} = 0.7788\,a\) to include the DC internal inductance \(\mu_0/(8\pi)\) of a solid round conductor — the convention of the assembled inductive stack (include_internal=True, the default of groundfield.coupling.inductance.thin_wire_self_inductance()).

    Limiting cases (all covered by the regression tests):

    • rho_1 == rho_2 — homogeneous Pollaczek, which matches carson_self_impedance() to well under 1 % in the reactance across 50 Hz – 1 kHz; the earth-return resistance sits slightly above \(\omega\mu_0/8\) (Carson's low-frequency, surface-return limit) and rises with burial depth and with frequency.
    • h_1 → ∞ — upper layer only; h_1 → 0 (conductor in layer 2) — lower layer only.
    • two-layer — the reactance lies within the [carson(rho_1), carson(rho_2)] bracket, weighted toward the deeper, more conductive layer at low frequency.

    r"""Effective vertical wavenumber :math:`u_\text{eff}(\lambda)` of a two-layer earth.

    The Tagg/Sunde/Wait tanh-recursion surface term: the input
    wavenumber of the layered earth seen from the **surface** (it sets the
    surface reflection coefficient :math:`(u_\text{eff}-\lambda)/
    (u_\text{eff}+\lambda)` of an overhead conductor). It is not the
    exponent of a buried conductor's kernel — the self and mutual
    impedances of this module use the exact buried amplitude since review
    pass 10 (finding 10.45). Reduces to the homogeneous half-space value :math:`u_1` when
    ``rho_1 == rho_2``, to :math:`u_1` as ``h_1 → ∞`` and to :math:`u_2`
    as ``h_1 → 0``. Units: 1/m.

    Parameters
    ----------
    lam
        Spectral (Hankel) variable, 1/m.
    rho_1, rho_2
        Upper / lower layer resistivity in Ω·m.
    h_1
        Upper-layer thickness in m.
    omega
        Angular frequency in rad/s.

    Returns
    -------
    complex
        Effective wavenumber :math:`u_\text{eff}` in 1/m.
    """
    u1 = cmath.sqrt(lam * lam + 1j * omega * MU_0 / rho_1)
    if rho_1 == rho_2:
        return u1
    u2 = cmath.sqrt(lam * lam + 1j * omega * MU_0 / rho_2)
    t = cmath.tanh(u1 * h_1)
    return u1 * (u2 + u1 * t) / (u1 + u2 * t)

    path — the term a self impedance alone omits. It carries **no
    internal-conductor term** (the two conductors are galvanically separate;
    the coupling is purely inductive through the soil), so with ideal
    (:math:`\approx 0\,\Omega`) earthing at both ends the coupling impedance
    of a parallel run of length :math:`\ell` is :math:`Z'_\text{M}\,\ell`.
    Together with two self impedances it forms the :math:`2\times2` loop
    impedance matrix of the coupled pair.

    Limiting behaviour (covered by the tests): it reduces to the homogeneous
    Carson mutual impedance
    (:func:`~groundfield.references.earth_return.carson_mutual_impedance`)
    when :math:`\rho_1 = \rho_2` (reactance to well under 1 % at low
    frequency), its magnitude is below the self impedance and decays
    monotonically with the separation :math:`x`, and its two-layer reactance
    lies within the two homogeneous Carson bounds, deep-layer dominated at
    low frequency.

    Parameters
    ----------
    rho_1, rho_2, h_1, frequency
        Two-layer earth resistivities (Ω·m), upper-layer thickness (m) and
        frequency (Hz), as in :func:`pollaczek_self_impedance`. Set
        ``rho_1 == rho_2`` for a homogeneous earth.
    depth_i, depth_j
        Burial depths of the two conductors in m. Must be positive.
    separation
        Horizontal centre-to-centre distance :math:`x` between the
        conductors in m. Must be non-negative; ``separation == 0`` is
        allowed only when ``depth_i != depth_j`` (one conductor directly
        above the other). Coincident conductors (``separation == 0`` and
        ``depth_i == depth_j``) are the self case — use
        :func:`pollaczek_self_impedance`.

    Returns
    -------
    complex
        Mutual series impedance :math:`R'_\text{M} + jX'_\text{M}` in Ω/m.

    Notes
    -----
    Earth-return coupling only: quasi-static, no displacement current. The
    vertical decay in the soil is governed by :math:`u_1`, not by Carson's
    air kernel :math:`e^{-(h_i+h_j)\lambda}`. As :math:`x \to \mathrm{GMR}`
    with :math:`depth_i = depth_j` it recovers
    :func:`pollaczek_self_impedance`.

    Raises
    ------
    ValueError
        If ``rho_1``, ``rho_2``, ``h_1``, ``frequency``, ``depth_i`` or
        ``depth_j`` is not positive and finite, if ``separation`` is
        negative, or if the two conductors coincide (``separation == 0``
        and ``depth_i == depth_j``).
    """
    _check_positive(
        rho_1=rho_1,
        rho_2=rho_2,
        h_1=h_1,
        frequency=frequency,
        depth_i=depth_i,
        depth_j=depth_j,
    )
    if separation < 0.0:
        raise ValueError(f"separation must be non-negative, got {separation}")
    omega = 2.0 * math.pi * frequency
    x = separation
    d = math.hypot(x, depth_i - depth_j)
    if d <= 0.0:
        raise ValueError(
            "coincident conductors (separation == 0 and depth_i == depth_j); "
            "use pollaczek_self_impedance for the self case"
        )
    if rho_1 == rho_2:
        rho_2, h_1 = rho_1, max(h_1, 1e3 * max(depth_i, depth_j))
    same_layer = (depth_i < h_1) == (depth_j < h_1)
    head = 0.0j
    if same_layer:
        rho_k = rho_1 if depth_i < h_1 else rho_2
        gamma = cmath.sqrt(1j * omega * MU_0 / rho_k)
        head = complex(kv(0, gamma * d))
    integral = _spectral_integral(rho_1, rho_2, h_1, omega, depth_i, depth_j, x)
    return 1j * omega * MU_0 / (2.0 * math.pi) * (head + integral)

    r"""Layered Pollaczek earth-return **self** impedance per unit length (Ω/m).

    Exact two-layer, buried-conductor series impedance
    :math:`Z' = R' + jX'` (quasi-static), earth-return only — no internal
    conductor resistance; the internal inductance is included only through
    ``gmr`` (see the module docstring). Reduces to Pollaczek's homogeneous
    form for ``rho_1 == rho_2`` and agrees with
    :func:`carson_self_impedance` in the reactance.

    Parameters
    ----------
    rho_1, rho_2
        Upper / lower layer resistivity in Ω·m. Must be positive. Set
        equal for a homogeneous earth.
    h_1
        Upper-layer thickness in m. Must be positive (ignored when
        ``rho_1 == rho_2``).
    frequency
        Frequency in Hz. Must be positive.
    depth
        Burial depth of the conductor in m. Must be positive; a depth
        ``>= h_1`` places the conductor in the lower layer.
    gmr
        Geometric mean radius of the conductor in m: the physical wire
        radius for an external-inductance model, ``0.7788·a`` to include
        the internal inductance of a solid round conductor. Must be
        positive.

    Returns
    -------
    complex
        Earth-return series impedance :math:`R' + jX'` in Ω/m.
    """
    _check_positive(
        rho_1=rho_1,
        rho_2=rho_2,
        h_1=h_1,
        frequency=frequency,
        depth=depth,
        gmr=gmr,
    )
    omega = 2.0 * math.pi * frequency
    if rho_1 == rho_2:
        rho_2, h_1 = rho_1, max(h_1, 1e3 * depth)  # one layer: no interface term
    rho_k = rho_1 if depth < h_1 else rho_2
    gamma = cmath.sqrt(1j * omega * MU_0 / rho_k)
    head = complex(kv(0, gamma * gmr))
    integral = _spectral_integral(rho_1, rho_2, h_1, omega, depth, depth, 0.0)
    return 1j * omega * MU_0 / (2.0 * math.pi) * (head + integral)
