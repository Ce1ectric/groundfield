# Glossary (English / German)

The documentation and the code use English terms; the German terms are
those of DIN EN 50522 (VDE 0101-2), DIN 18014 and the German network
practice. Names of releases up to 0.15.0 that were German (`kvs`,
`OrtsnetzLayout`, …) are listed under [Deprecations](deprecations.md).

## Network and installation

| English | German | Meaning in groundfield |
|---|---|---|
| LV network | Ortsnetz | low-voltage distribution network supplied by one MV/LV substation; generated by `TnNetworkGenerator` / `LvNetworkLayout` |
| MV/LV substation, substation | Ortsnetzstation (ONS) | transformer station feeding an LV network; `substation` in the generators |
| cable distribution cabinet | Kabelverteilerschrank (KVS) | street cabinet that branches the LV cables; `cabinet` in the generators (`kvs` up to 0.15.0) |
| service connection | Hausanschluss (HA), Hausanschlusskasten (HAK) | connection of a building to the LV network; the service drop of the PEN network |
| single-family house | Einfamilienhaus (EFH) | the `residential` building type |
| multi-family house | Mehrfamilienhaus (MFH) | |
| small / medium commercial building | Gewerbe (klein / mittel) | the `small_industry` / `medium_industry` building types |
| TN system | TN-System | LV system whose neutral is earthed at the substation and connected to the exposed parts through the PEN / PE conductor |
| PEN conductor | PEN-Leiter | combined protective and neutral conductor; joins the earthing systems of an LV network (`conductor_type="pen"`) |
| cable screen | Kabelschirm | metallic screen of a power cable; an earth-return path in parallel to the soil |
| overhead line, earth wire | Freileitung, Erdseil | `conductor_type="overhead"`; $z < 0$ |
| MV network | Mittelspannungsnetz | the network of work package AP2 |
| neutral earthing | Sternpunktbehandlung | decides the earth-fault current in the MV network |
| single-line-to-earth fault | einpoliger Erdfehler, Erdschluss / Erdkurzschluss | fault that drives the current into the earthing systems |
| harmonics | Oberschwingungen | frequency components of a fault current up to 1 kHz (`touch_voltage_spectrum`) |
| work packages AP1, AP2 | Arbeitspakete | AP1: model of the TN LV network (catalogue of real networks); AP2: earthing system of the MV network |

## Earthing system

| English | German | Meaning in groundfield |
|---|---|---|
| earthing system | Erdungsanlage | all electrodes and earthing conductors of an installation |
| interconnected (global) earthing system | vernetztes / globales Erdungssystem | earthing systems joined by PEN conductors and cable screens so that no dangerous touch voltage arises (EN 50522) |
| earth electrode | Erder | conductor in contact with the soil (`Electrode`) |
| foundation earth electrode | Fundamenterder | closed conductor in the foundation of a building (DIN 18014); `FoundationElectrodeSpec`, usually encased in concrete |
| ring earth electrode | Ringerder | `RingElectrode`, or a closed `PolylineElectrode` around a building |
| driven rod, rod electrode | Tiefenerder, Staberder | `RodElectrode` |
| strip electrode | Banderder, Oberflächenerder | `StripElectrode` |
| star earth electrode | Strahlenerder, Sternerder | `StarElectrode` |
| mesh earth electrode, grid | Maschenerder, Erdungsnetz | `MeshElectrode`, `GridMeshElectrode` |
| earthing conductor, bonding conductor | Erdungsleiter, Verbindungsleitung | `Conductor` between electrodes |
| concrete encasement | Betonummantelung | shell of concrete around a foundation earth; per-length coefficient `concrete_shell_coefficient_ohm_m` |
| penetration | Durchdringung | share of buildings that have a foundation earth electrode |
| galvanic cluster | galvanisch verbundener Erderverbund | electrodes joined by ideal conductors; one potential |
| junction | Knoten (ohne Erdkontakt), Muffe | node of the conductor network without soil contact (`Junction`): cable joint, instrument terminal |

## Soil and fields

| English | German | Symbol | Meaning |
|---|---|---|---|
| soil resistivity | spezifischer Erdwiderstand | $\rho$, $\rho_E$ | Ω·m; `rho`, `rho_1`, `rho_2` |
| two-layer soil | Zweischichtboden | | upper layer $\rho_1$, thickness $h_1$, half-space $\rho_2$ |
| layer thickness | Schichtdicke | $h_1$ | m |
| reflection coefficient | Reflexionsfaktor | $K$ | $(\rho_2 - \rho_1)/(\rho_2 + \rho_1)$ |
| remote earth | Bezugserde | | potential reference, $\varphi \to 0$ far away |
| soil surface | Erdoberfläche | $z = 0$ | depth $z$ positive downwards |
| skin depth (in the soil) | Eindringtiefe | $\delta$ | $\sqrt{2\rho/(\omega\mu_0)}$ |
| earth return | Erdrückleitung | | path of a current through the soil back to its source; enters the inductive coupling |
| mutual inductance | Gegeninduktivität | $M$ | Neumann integral between two conductor segments |

## Quantities

| English | German | Symbol | Meaning in groundfield |
|---|---|---|---|
| earth potential rise (EPR) | Erdungsspannung | $U_E$ | potential of an earthing system against remote earth |
| grounding impedance, earthing impedance | Erdungsimpedanz | $Z_E$ | $U_E / I$; three variants below |
| input impedance | Eingangsimpedanz | $Z_\text{in}$ | $(\varphi_a - \varphi_r)/I_s$ at a source: what an earth tester or a fault sees (`input_impedance`) |
| cluster impedance | Erdungsimpedanz des Erderverbunds | $Z_c$ | cluster potential over the current the cluster leaks itself (`cluster_impedance`) |
| electrode impedance | Erdungsimpedanz eines Erders | | cluster potential over one electrode's leakage current (`grounding_impedance`) |
| grounding resistance, spreading resistance | Erdungswiderstand, Ausbreitungswiderstand | $R_E$, $R_A$ | real part of the grounding impedance at low frequency |
| mutual grounding impedance | Koppelimpedanz | $Z_{ij}$ | potential of cluster $i$ per ampere leaking from cluster $j$ (`solve_mutual_matrix`) |
| touch voltage | Berührungsspannung | $U_T$ | EPR minus the surface potential 1 m from the touched part (`touch_voltage`) |
| prospective touch voltage | Leerlauf-Berührungsspannung (prospektive B.) | $U_{vT}$ | open-circuit touch voltage, before body and footwear resistances (EN 50522, Annex B) |
| permissible touch voltage | zulässige Berührungsspannung | $U_{Tp}$ | EN 50522 Table B.4 as a function of the fault duration |
| step voltage | Schrittspannung | $U_S$ | surface potential difference over one step of 1 m (`step_voltage`) |
| fault duration | Fehlerdauer | $t_F$ | s |
| current sharing | Stromaufteilung | | currents of the electrodes and conductors (`cluster_current_balance`) |
| split factor | Aufteilungsfaktor | $s$ | share of a source current that leaves the feeding cluster through the soil (`split_factor`) |
| reduction factor | Reduktionsfaktor | $r$ | share of an earth-fault current that returns through the soil instead of cable screens and earth wires (inductive; not computed) |
| rho-f model | ρ-f-Modell, ρ-f-Funktion | $Z(\rho, f)$ | reduced model of an earthing system over resistivity and frequency, exported to groundinsight |
| characteristic matrix | charakteristische Matrix | $(\mathbf{Y}_L + \mathbf{Y}_G)\,\mathbf{u} = \mathbf{i}$ | nodal description of an LV network: line admittances plus the inverse of the mutual grounding-impedance matrix |

## Measurement

| English | German | Meaning in groundfield |
|---|---|---|
| fall-of-potential measurement | Erdungsmessung (Strom-Spannungs-Verfahren) | test current between the earthing system and an auxiliary electrode, voltage measured with a probe (`MeasurementSetupConfig`) |
| auxiliary (current) electrode | Hilfserder | return electrode of the test current (terminal H of the instrument) |
| probe | Sonde | voltage probe (terminal S) |
| current lead, probe lead | Stromzuleitung, Sondenleitung | measurement leads, overhead or buried (`overhead_lead`, `buried_lead`); inductively coupled to the PEN network |
| earth tester | Erdungsmessgerät | `measured_impedance(result)`: probe voltage over test current |

## Terms of the package

| Term | Meaning |
|---|---|
| `World` | the physical model: soil, electrodes, junctions, conductors, sources |
| `Engine` | the numerics: backend, frequencies, segment length, kernel, earth-return model |
| backend | a registered numerical method (`image`, `image_2layer`, `mom`, `mom_sommerfeld`, `fem`) |
| kernel | how a segment's current enters the Green's function: `"line"` (exact uniform line source) or `"point"` (midpoint point source) |
| segment | straight piece of a discretised wire, at most `segment_length` long |
| owner | electrode and soil layer that carries one unknown current in the image family |
| BusType | groundinsight's model of a network node with an impedance formula in `f` and `rho` |
